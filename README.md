# Healthy Call — releases

Android release APKs and the `update.json` manifest used by the app's auto-updater.

The source code is private. The app only works with an account on our server.

Install: download the latest `healthycall-x.y.z.apk` from [Releases](../../releases/latest) and open it on your phone (allow "Install unknown apps" once). After that the app updates itself.
